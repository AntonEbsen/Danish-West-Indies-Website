# Scripts

Narration scripts — one Markdown file per video, numbered to match the slate in
[`../series_plan.md`](../series_plan.md). These are the words we say plus the
on-screen / b-roll cues that go with them; they're committed so we can review and
revise them like any other writing.

## Contents

- [`_template.md`](_template.md) — copy this to start a new script.
- [`01_findings_explainer.md`](01_findings_explainer.md)
- [`02_methods_walkthrough.md`](02_methods_walkthrough.md)
- [`03_process_diary.md`](03_process_diary.md)

## How to write one

1. Copy [`_template.md`](_template.md) to `NN_slug.md` (same number/slug as the
   row in [`../series_plan.md`](../series_plan.md)).
2. Write the **hook** first (the first 10 seconds decide whether anyone keeps
   watching), then the beats, then the narration.
3. In the right-hand **on-screen** column, point at real assets where you can —
   a figure in `results/figures` or a slide from
   `slides` — so editing is just "show this here".
4. Keep claims honest and sourced; cite from
   `references/citation.bib` when stating a
   fact or a number on screen.
