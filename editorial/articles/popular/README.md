# Popular / blog articles

General-audience write-ups — for a project blog, Medium, Substack, or a
university news page. Plain language, the story first, the methodology last. One
Markdown file per article, numbered to match `dissemination/pipeline.md`.

## Contents

- [`_template.md`](_template.md) — copy this to start a new article.
- [`01_findings_for_a_general_audience.md`](01_findings_for_a_general_audience.md)

## How to write one

1. Copy [`_template.md`](_template.md) to `NN_slug.md` (same number as the row in
   `dissemination/pipeline.md`).
2. Lead with the **finding**, not the background — a reader decides in the first
   two sentences whether to keep going.
3. Condense from the thesis (`thesis`) rather than
   re-writing; reuse a plot from `results/figures`.
4. Link claims to sources, but keep jargon and citations light — link out instead
   of using `\autocite`.
5. One sentence per line (clean diffs).
