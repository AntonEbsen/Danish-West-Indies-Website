# Op-ed / press articles

Short, argument-driven pieces pitched to newspapers or magazines. Unlike the
[popular](../popular/) explainer, an op-ed makes a **claim** and defends it,
hung on a current news peg. Tight word limits (most outlets: 600–900 words). One
Markdown file per piece, numbered to match `dissemination/pipeline.md`.

## Contents

- [`_template.md`](_template.md) — copy this to start a new op-ed.
- [`01_oped.md`](01_oped.md)

## How to write one

1. Copy [`_template.md`](_template.md) to `NN_slug.md`.
2. Open with the **news peg** (why now), then state your **argument** in one
   sentence — everything after defends it.
3. Respect the outlet's word limit; op-eds are cut hard.
4. End with a clear "so what" / call to action.
5. Pitch tracking (outlet, editor, status) lives in
   `dissemination/pipeline.md`; most outlets want exclusivity, so pitch one
   at a time.
